# 🧠 Memo Card

Memo Card adalah aplikasi kuis sederhana yang dibuat menggunakan *Python* dan *PyQt5*.

Aplikasi ini menampilkan pertanyaan dengan empat pilihan jawaban. Pengguna dapat memilih jawaban dan mendapatkan informasi apakah jawabannya benar atau salah. Posisi pilihan jawaban juga diacak agar kuis menjadi lebih menarik.

## 🎯 Fitur

- 📝 Menampilkan pertanyaan kuis
- 🔘 Menyediakan 4 pilihan jawaban
- 🔀 Mengacak posisi pilihan jawaban
- ✅ Mengecek jawaban benar atau salah
- 💡 Menampilkan jawaban yang benar
- ➡️ Berpindah ke pertanyaan berikutnya
- 🔄 Mengulang pertanyaan setelah semua soal selesai

## 🛠️ Teknologi yang Digunakan

- Python
- PyQt5
- Random
